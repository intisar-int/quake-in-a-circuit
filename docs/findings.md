# Findings, checks and known limitations

## What was verified

| Check | Method | Result |
|---|---|---|
| Mechanical Simscape vs. state-space | Subtract scopes in `models/mech_comp.slx` | Differences ~10⁻²⁰ (solver round-off) |
| State-space vs. second-order equations | `python/verify_and_plot.py`: `lsim` against a Radau solve of `M x'' + C x' + K x = F` | 0.005 % max relative difference |
| Electrical state-space vs. mesh equations | Same script, mesh form `L q'' + R q' + S q = V` | 0.005 % max relative difference |
| Sensitivity percentages | MATLAB script vs. Python re-implementation | Identical to two decimals |

The 0.005 % difference between `lsim` and the second-order solve comes from `lsim` interpolating the sampled input between 1 ms steps. It is not a modelling error.

## What the "zero error" between building and circuit means

With L = m, R = c and C = 1/k, the electrical state-space matrices are numerically identical to the mechanical ones, so overlaying their responses in `building_vs_circuit.m` gives exactly zero error. That confirms the parameter mapping and the plumbing, but it cannot catch a mistake in the shared equations. The independent evidence comes from the Simscape comparisons (physical-network solver vs. state-space) and the second-order re-solve in Python.

## Units and magnitudes

- Peak inter-story drift is **0.13 µm** (1.3×10⁻⁷ m), not 0.13 mm. The MATLAB scripts print drift with `%.4f m`, which shows `0.0000`, so the values only appear on the plot axes (×10⁻⁴ mm). The same applies to the sensitivity printout, whose percentages are right but whose absolute drifts all read `0.0000 m`.
- Peak floor displacement is about 94 µm and settles to about ±52 µm. The parameters are scaled textbook values, so the absolute motion is much smaller than for a real building.
- Both floors move almost identically (x₁ ≈ x₂), which is why the drift is three orders of magnitude below the displacement.

## Circuit measurement note

The Simscape Electrical model reads **voltage across the capacitors** (`Capacitor Voltage (Displacement)`), which equals q/C = k·x, the spring force, not the charge itself. To compare with displacement, divide by k (multiply by C). The state-space scripts read charge directly.

## Analogy naming

The circuit implements the **force–voltage** (Maxwell) analogy: force → voltage, velocity → current, displacement → charge. Series-connected elements share the same current, so a floor's spring and damper appear as an R–C series pair.

## Slow transient

The slowest poles of A are at −0.1 and −1.0 rad/s, so the response has not fully reached steady state at 5 s: the first displacement peak is about 94 µm and the oscillation amplitude decays to about 52 µm over the run. The "settled" figures in the README use t ≥ 3 s.

## Known limitations

- The earthquake is a sinusoidal **force on floor 1**, not a recorded or random ground-acceleration time history.
- The structure is linear with constant coefficients and two degrees of freedom.
- Simscape results are taken from the original Simulink runs; they are not regenerated by the Python script.
- Models were saved with Simulink R2023a.
